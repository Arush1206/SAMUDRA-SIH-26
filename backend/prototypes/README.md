# SAMUDRA — Prototypes

Standalone single-file scripts that run with zero server/database setup.

| File | Purpose |
|------|---------|
| `engine3_prototype.py` | Engine 3 full pipeline on hardcoded Mumbai offshore scenario |

## Run
```bash
cd samudra/backend
source samudra/backend/prototypes/engine3/.venv/bin/activate
python prototypes/engine3_prototype.py
```
